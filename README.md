# Телеграм Компас

> 65 рабочих MTProxy для Telegram — живой список с проверкой пинга.

[![Сайт](https://img.shields.io/badge/сайт-operativerititle.github.io-2c259d)](https://operativerititle.github.io/)
[![Канал](https://img.shields.io/badge/Telegram-@MTProxy4free-2aabee)](https://t.me/MTProxy4free)

## Что внутри

- `65` проверенных прокси-серверов MTProxy: наши серверы Lite64 + отобранные публичные;
- проверка доступности прямо на странице (кнопка «Проверить все»);
- подключение в один клик — Telegram открывается сам;
- сайт устанавливается на телефон как приложение (PWA).

**Открыть список:** [https://operativerititle.github.io/](https://operativerititle.github.io/)

## Подключение вручную

Telegram → Настройки → Данные и память → Прокси → MTProto — или просто нажмите «Подключить» на сайте.
